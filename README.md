Ashen Issue Tracker
===================

This repository at [https://github.com/yasec-de/ashen-issues](https://github.com/yasec-de/ashen-issues) serves as the
central issue tracker for all ashen subprojects. All software issues are tracked here, as well as all issues related to
the Yanartas hardware.

For discussion and short questions that aren't an issue, please use our [signal
group](https://signal.group/#CjQKIF-_tl1MNxwXSaVg2Xi_6NgXUXnlBl_XCNJKdRSO4E_6EhCX_xbVzbdy3qQLIhmlZ6tO) (also at the qr
code below).
